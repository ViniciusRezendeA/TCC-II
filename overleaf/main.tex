\begin{resumo}
O \textit{Model Context Protocol} (MCP) permite que agentes de Inteligência Artificial (IA) interajam com sistemas externos por meio de ferramentas (\textit{tools}), cujas descrições em linguagem natural orientam sua utilização. Dessa forma descrições de baixa qualidade podem comprometer a eficácia desses agentes. Por este motivo este trabalho investiga o impacto do acesso ao código na avaliação dessas descrições. Para isso, 12.166 ferramentas de 206 repositórios de servidores MCP do GitHub são extraídas e avaliadas por três LLMs em dois cenários: com e sem código. Os resultados encontraram mudanças significativas nas notas que mostraram que a descrição pode omitir detalhes importantes da implementação que afetam sua avaliação de qualidade.
\end{resumo}

\begin{abstract}
The \textit{Model Context Protocol} (MCP) enables Artificial Intelligence (AI) agents to interact with external systems through tools, whose natural language descriptions guide their usage. Consequently, low-quality descriptions can compromise the effectiveness of these agents. For this reason, this work investigates the impact of code access on the evaluation of these descriptions. To this end, 12,166 tools from 206 MCP server repositories on GitHub were extracted and evaluated by three LLMs across two scenarios: with and without access to the source code. The results revealed statistically significant changes in the scores, showing that descriptions can omit important implementation details that affect their quality assessment.
\end{abstract}
