\begin{resumo}
O \textit{Model Context Protocol} (MCP) permite que agentes de Inteligência Artificial (IA) interajam com sistemas externos por meio de \textit{tools}, cujas descrições em linguagem natural orientam sua utilização. Entretanto, descrições de baixa qualidade, caracterizadas pela presença de \textit{smells}, podem comprometer a eficácia desses agentes. Nesse contexto, este trabalho \textcolor{red}{realiza um} estudo sobre \textcolor{green}{a avaliação da qualidade dessas descrições por meio de uma rubrica multidimensional, da qual se derivam deficiências associadas a} \textit{smells} \textcolor{green}{em ferramentas MCP}, incorporando o código das ferramentas ao processo de avaliação. Para isso, são minerados repositórios de servidores MCP no GitHub e realizadas avaliações automatizadas das descrições das \textit{tools}. O objetivo é comparar resultados obtidos a partir das descrições com aqueles enriquecidos pelo código da ferramenta. Espera-se demonstrar que a inclusão desse contexto técnico revela inconsistências entre descrição e implementação, tornando mais precisa a avaliação de qualidade e \textcolor{green}{a identificação} desses \textit{smells}.
\end{resumo}

\begin{abstract}
The \textit{Model Context Protocol} (MCP) enables Artificial Intelligence (AI) agents to interact with external systems through \textit{tools}, whose natural language descriptions guide their usage. However, poor-quality descriptions, characterized by the presence of \textit{smells}, can compromise the effectiveness of these agents. In this context, this work \textcolor{red}{conducts a} study on \textcolor{green}{assessing the quality of these descriptions through a multidimensional rubric, from which deficiencies associated with} \textit{smells} \textcolor{green}{in MCP tools are derived}, incorporating the tools' source code into the evaluation process. To achieve this, MCP server repositories are mined from GitHub, and automated evaluations of tool descriptions are performed. The objective is to compare results obtained solely from descriptions with those enriched by the tool's code. It is expected to demonstrate that incorporating this technical context reveals inconsistencies between description and implementation, thereby improving both the quality assessment and \textcolor{green}{the identification} of these \textit{smells}.
\end{abstract}
